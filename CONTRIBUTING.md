# Contributing

Thanks for your interest in AURA. This repository is the **public documentation and brand home** for
the AURA Autonomous SRE Platform. The engine source is maintained in a separate private repository.

## What belongs here

- Documentation improvements (clarity, accuracy, typos)
- Architecture diagrams and explanations
- Market / competitive research corrections (with sources)
- Brand assets

## What does not belong here

- Engine source code or private implementation details
- Secrets, credentials, or customer data of any kind

## How to contribute

1. Open an issue describing the change (use a template in `.github/ISSUE_TEMPLATE`).
2. Fork, branch, and make your change.
3. Keep the honesty principle intact: never present a simulated/roadmap capability as shipped.
4. Open a pull request referencing the issue.

## Style

- Markdown, sentence case headings, wrapped at a comfortable width.
- Cite sources for any market or competitor claim with an inline link.
- Prefer clear prose over marketing superlatives.

## Code of conduct

By participating you agree to the [Code of Conduct](CODE_OF_CONDUCT.md).
